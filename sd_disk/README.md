## Embedded Linux binaries for boards

This directory contains files and instructions to create SD card for Enclustra XU8+ST1 and Digilent ZyboZ7-20 boards.

**Directories:**

- `./xu8_rec/`. Enclustra XU8+ST1 10Gb Ethernet wire speed and FMCXM105 DIO capture demo (description in [README.md](./xu8_rec/README.md)).
- `./xu8_cam/`. Enclustra XU8+ST1 10Gb Ethernet and RaspberryPi HQ (IMX477) camera test (description in [README.md](./xu8_cam/README.md)).
- `./zyboz7_cam/`. Digilent ZyboZ7-20 1Gb Ethernet and RaspberryPi HQ (IMX477) camera test (description in [README.md](./zyboz7_cam/README.md)).
- `./pzsdr1_sdr/`. PicoZED SDR++ test (description in [README.md](./pzsdr1_sdr/README.md)).
